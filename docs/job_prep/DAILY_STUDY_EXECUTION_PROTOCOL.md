# 每日公考执行协议｜V2.3 广度优先期

V2.3于2026-11-16按用户最新“广度优先遍历、学完再强化”指令生效；[唯一主计划](CIVIL_SERVICE_MASTER_PLAN.md)与[BFS细案](BFS_FIRST_PASS_2026-11-16.md)优先。旧V2.2按T+7先复测、周五必须综合混合的日程已经废止；历史成绩不改。[逐日课表](CIVIL_SERVICE_TIMETABLE_2026-10_TO_2027-01.md)只给未来主题，仍须核已学/未学证据。

## 开课前教学闸门（每次必须执行，不占用额外作业量）

教师在发第一道“新课题”前，必须读取或核对：覆盖表→学习状态→复习队列→最近同模块daily，并把当天子点标为`NEW`、`REVIEW_OR_TRANSFER`或`CLOSED`。

执行优先级（**BFS模式**）：
1. 先读29讲覆盖表与最新日报，按`NOT_COVERED / PARTIAL_COVERAGE / FIRST_PASS_COVERED`查真正未学习的核心子点；**不先执行旧T+7复测卡**。
2. 先教一个未覆盖知识点的识别条件和方法，再给学生**一题独立代表题**；记首次答案、必要纠错和覆盖状态。错了不在原方法反复出新题直到PASS，直接转到下一尚未覆盖的子点。
3. 已接触知识只作为新知识的必要前置（1—3句话）、不重新铺开复习；当用户说学过应核证据后跳过。
4. 每日累计推进**尽可能多的真实新子点**（视难度1—3点或更多），不能牺牲理解底线或伪称会做。每周不得只报旧题复测正确率，要明确实际新增首次覆盖节点。
5. 旧`REV-*`记录、原到期日、错误、PASS都留存；未测的标`DEFERRED_BY_BFS_POLICY / NOT_ATTEMPTED`。只有BFS第一轮完成或用户明示切换后才进行DFS强化。

## 120分钟容量：代表题少而有覆盖，时间到就结束

**公考约2小时、STM32约2小时，合计每日约4小时；两门各自收尾，不互相挤占，不用晚间或周末自动补齐。** 公考正常北京时间09:00—11:00；临时改开课时间时明确当次截止，不默认滚动延长。

| 环节 | 120分钟内的预算 |
|---|---:|
| 接续点和真正未学入口 | 5分钟 |
| 方法教学 | 约25分钟 |
| 学生独立作答 | 约50分钟 |
| 批改和必要讲解 | 约25分钟 |
| 休息 | 5分钟 |
| 收尾、记录下次入口 | 10分钟 |

教学、作答、讲解交错进行，可随难度在总预算内调整；不是另加三块作业。每日申论、周二四政治/常识均已包含。

**学科分段（周一至周五，BFS期）**

| 时段 | 内容 | 边界 |
|---|---|---|
| 09:00—09:05 | 核对最新断点、未答题和真实未覆盖子点 | 不强制旧T+7 |
| 09:05—10:00 | 当日行测未覆盖方法；周五优先补本周新覆盖缺口 | 少量代表题，不为同一题型刷到熟练 |
| 10:00—10:05 | 休息 | 不算作答 |
| 10:05—10:35 | 每日申论下一未学方法或实际写作步骤 | 保留真实独立短答，不用教师范文代替 |
| 10:35—10:50 | 周二四政治/常识短块；周一三五可补未覆盖子点或完成当前反馈 | **10:45最迟停止新题**，长题按完整周期更早停止 |
| 10:50—11:00 | 收尾，登记新覆盖、薄弱线索、待答/待讲解及下次入口 | 不再发“最后一题”，11:00结束 |

周五也是新课补缺日，不强制四科混合复测；周覆盖盘点放进收尾，不额外增加第三套作业。图不可读或材料不足时，在剩余预算内切换到可读缺口；若已不够一个完整周期，就结束，不用乱码替代题目。

### 动态题量与发题闸门

1. 一个真正新的核心子点通常讲清后做**1道代表题**；确有另一个必要边界时才考虑第2道，不同数字的同法题不自动算新子点。**同一题型不要安排大量重复练习**。
2. 复杂题/长材料日可能只有几道，短辨析日可以十几道；数字只是容量现象，**不是每日最低题量、完成指标或卡片配额**。申论长答按真实产出记，不为题数拆分。
3. 每次只发布当前一道待答题。发题前估算教学＋独立作答＋批改是否能在收尾前结束，放不下就不发；不能为赶覆盖省掉学生独立作答。
4. 首答错只讲最关键错因、记录待DFS并前进，不要求当堂正确或熟练；前置概念确实阻塞后续时补必要解释，同时删减后面的新内容，不延长截止。
5. **最迟第105分钟停新题，第110分钟收尾，第120分钟结束**。用户提前说停立即收尾；只有用户明确要求本次继续才另定边界，不以“还差一题”擅自加时。

### 未答、未讲完和超时接续

- **已发未答**：原题、数字、选项、图形位置和来源原样保留；`UNANSWERED / NOT_SCORED`，不判错、不猜答案、不提前给答案或暗示。下次核实没有更新作答后，先恢复同一题。
- **已答未讲完**：逐字首答封存，注明已给提示/讲解范围，下次从剩余反馈接续，不换数据让学生重做。
- **尚未发题**：保持`NOT_COVERED`或原部分覆盖状态，进入后续正常课日，不形成欠题或周末补课。
- 到截止只收口状态，不再开启教学。截止后收到答案可保存原答，后续教学留到下次；未得到用户明确继续指令，不默默延长。
- 开课/结束时间用于控制课堂窗口，不等于专注学习实测。未可靠计时仍写`NOT_MEASURED`，不从消息间隔推算学时。

**BFS→DFS切换条件**：29讲的核心方法皆至少系统讲过并有独立代表题首答；部分标题接触不等于覆盖全讲。完成时可开始DFS旧错和新情境复测。政治常识及材料分析仍保留独立追踪。原2027年1月整卷A→修复→B日期原则不变，若BFS未完按实调整缺口，不能冒称完课。
## 评分和纠错

在正式DFS复测中，独立方法与结果正确才可判本轮PASS；BFS独立首答与首轮覆盖不自动升级为正式复测PASS。答案正确但方法未展示记ANSWER_PASS/METHOD_UNVERIFIED；教师提示后记GUIDED；输入歧义记UNCLEAR，允许一次不含解法的文字确认，不能自行判为计算错误。没有准确计时就写NOT_MEASURED，不从消息间隔推断学习时长。

讲错因不等于立即补题。BFS期首答错误原样保留并登记`NEEDS_DFS_REVIEW`，暂不实施到期T+7；真正进入DFS期后恢复各卡一题新情境复测、失败后的针对性教学与按规则重排。新方法代表题至少需学生独立作答；无需每个小题写长证明。不得为凑覆盖量延长时间或以教师示范冒充学生首答。

## 轻量薄弱地图，不新增繁琐归档

沿用原卷、覆盖表和现有错因字段，简记：**题目定位→知识点→首答/辅助情况→最关键错因→待DFS事项**。不要求学生另写长篇错题报告，不新建第二套成绩库。

- 错题：保留真实首答，错因不确定时写待核，记薄弱线索和`NEEDS_DFS_REVIEW`。
- 未答：`UNANSWERED / NOT_SCORED`，不是错误，不当覆盖完成。
- 辅助完成：记录提示级别，不能当独立掌握。
- 独立正确：只有选项正确而无方法证据时仍为`ANSWER_PASS / METHOD_UNVERIFIED`。
- 独立掌握：需要相应方法和独立迁移证据；单题对或错都不武断推断整讲掌握程度。

首轮结束后依据反复错误、关键前置和高频应用的证据优先强化薄弱点，而不是把所有旧题再刷一遍。每日收尾只需简明交代新接触子点、真实首答/辅助、待DFS线索和下一接续点；周五据同一证据核对尚未覆盖内容。

## 保存与权限

用户真实原答优先写public-exam-knowledge/records/sessions；学习状态、队列和交接只写摘要并引用原件。计划更新记PLAN_APPROVED，不生成新的成绩。读最新SHA后做最小安全变更，回读核验再说已同步；失败明确未同步范围。公开库不放商业资料、私密简历、整套受保护教材。

此120分钟只用于公考。科研/技术/求职义务照既有授权，不因本协议自动启动Linux项目、面经、环境配置、板卡寄送或招聘投递。周末休息；节假日/实习冲突用已有弹性格替换，不叠加补课。
