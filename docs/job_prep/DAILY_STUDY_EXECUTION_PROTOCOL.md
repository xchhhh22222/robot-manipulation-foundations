# 每日公考执行协议｜V2.3 广度优先期

V2.3于2026-11-16按用户最新“广度优先遍历、学完再强化”指令生效；[唯一主计划](CIVIL_SERVICE_MASTER_PLAN.md)与[BFS细案](BFS_FIRST_PASS_2026-11-16.md)优先。旧V2.2按T+7先复测、周五必须综合混合的日程已经废止；历史成绩不改。[逐日课表](CIVIL_SERVICE_TIMETABLE_2026-10_TO_2027-01.md)只给未来主题，仍须核已学/未学证据。

## 开课前教学闸门（每次必须执行，不占用额外作业量）

教师在发第一道“新课题”前，必须读取或核对：覆盖表→学习状态→复习队列→最近同模块daily，并把当天子点标为`NEW`、`REVIEW_OR_TRANSFER`或`CLOSED`。

执行优先级（**BFS模式**）：
1. 先读29讲覆盖表与最新日报，按`NOT_COVERED / PARTIAL_COVERAGE / FIRST_PASS_COVERED`查真正未学习的核心子点；**不先执行旧T+7复测卡**。
2. 先教一个未覆盖知识点的识别条件和方法，再给学生**一题独立代表题**；记首次答案、必要纠错和覆盖状态。错了不在原方法反复出新题直到PASS，直接转到下一尚未覆盖的子点。
3. 已接触知识只作为新知识的必要前置（1—3句话）、不重新铺开复习；当用户说学过应核证据后跳过。
4. 每日累计推进**尽可能多的真实新子点**（视难度1—3点或更多），不能牺牲理解底线或伪称会做。每周不得只报旧题复测正确率，要明确实际新增首次覆盖节点。
5. 旧`REV-*`记录、原到期日、错误、PASS都留存；未测的标`DEFERRED_BY_BFS_POLICY / NOT_ATTEMPTED`。只有BFS第一轮完成或用户明示切换后才进行DFS强化。

**BFS期间周一至周四：北京时间09:00—11:00**（是时间预算，未实测不得写已学120分钟）

| 时段 | 内容 | 验收边界 |
|---|---|---|
| 09:00—09:05 | 核对昨日报与今天未覆盖入口 | 不做强制旧卡T+7 |
| 09:05—10:05 | 当日行测真正未覆盖方法，尽力推进1—3个子点 | 每点至少一个学生独立代表题；错点仅登记，先向前推进 |
| 10:05—10:10 | 休息 | 不算作答 |
| 10:10—10:40 | 每日申论**下一未学方法** | 短材料真实首答；不重复一整堂旧对策题 |
| 10:40—10:55 | 周一/三再推进一个未覆盖子点；周二/四保留政治/常识短块 | 政策法规时需核官方原文；不加班 |
| 10:55—11:00 | 记录今日新增覆盖节点、错因待DFS、下一入口 | 提交只有已实际作答的成绩；日程本身不是PASS |

**BFS期间周五**：09:00—10:05补本周未完成的判断/言语/资料/数量全新节点（或交叉拓宽，一题首答为最低证据）；10:05—10:10休息；10:10—10:45申论新题型/写作推进；10:45—11:00核对29讲覆盖新增与剩余。周五**不是强制混合复测日**。没有读图清晰的新图时切换到可读的另一缺口，不用乱码替代新课。

**BFS→DFS切换条件**：29讲的核心方法皆至少系统讲过并有独立代表题首答；部分标题接触不等于覆盖全讲。完成时可开始DFS旧错和新情境复测。政治常识及材料分析仍保留独立追踪。原2027年1月整卷A→修复→B日期原则不变，若BFS未完按实调整缺口，不能冒称完课。
## 2026-11-25批准：每日申论专项执行

按[申论专项细案](methods/ESSAY_SKILL_TRAINING_2026-11-25.md)内嵌在原申论时段，优先审题拆解、材料定位、关键词压缩、公文结构。A阶段3—5工作日建议：每次新材料，先等学生独立列任务槽，再逐步收证据关键词、精炼/短答、自查；B阶段5—7工作日建议：自主拆解与证据→完整短答→自查；C阶段无提示新材料独立验证。按证据切换，不因天数自动达标。教师不提前提供具体槽位/材料答案；需提示时记录GUIDED，不把示范后复述当独立掌握。原10:10—10:40申论块及周五时段不增加；兼顾未学题型，行测继续BFS，旧T+7保持延期。

## 评分和纠错

独立方法与结果正确＝正式复测PASS；否则本轮未通过。答案正确但方法未展示记ANSWER_PASS/METHOD_UNVERIFIED；教师提示后记GUIDED；输入歧义记UNCLEAR，允许一次不含解法的文字确认，不能自行判为计算错误。没有准确计时就写NOT_MEASURED，不从消息间隔推断学习时长。

讲错因不等于立即补题。BFS期首答错误原样保留并登记`NEEDS_DFS_REVIEW`，暂不实施到期T+7；真正进入DFS期后恢复各卡一题新情境复测、失败后的针对性教学与按规则重排。新方法代表题至少需学生独立作答；无需每个小题写长证明。不得为凑覆盖量延长时间或以教师示范冒充学生首答。

## 保存与权限

用户真实原答优先写public-exam-knowledge/records/sessions；学习状态、队列和交接只写摘要并引用原件。计划更新记PLAN_APPROVED，不生成新的成绩。读最新SHA后做最小安全变更，回读核验再说已同步；失败明确未同步范围。公开库不放商业资料、私密简历、整套受保护教材。

此120分钟只用于公考。科研/技术/求职义务照既有授权，不因本协议自动启动Linux项目、面经、环境配置、板卡寄送或招聘投递。周末休息；节假日/实习冲突用已有弹性格替换，不叠加补课。
