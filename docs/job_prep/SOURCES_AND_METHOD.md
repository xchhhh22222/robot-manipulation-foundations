# 来源可信度与刷题整理规范

## 1. 四类信息分开存

| 标记 | 定义 | 写入方式 |
| --- | --- | --- |
| OFFICIAL | 国考官方大纲、企业正式招聘公告、官方测评产品介绍 | 原文仅摘要、附时间/URL、区分适用届别 |
| EXPERIENCE | 牛客/脉脉/社区求职者个人一手面经 | 只记录用户公开描述的考点、环节、时间、链接；不复制全文 |
| SECONDARY | 辅导网站、题型总结、二手整理 | 需标明未经企业证实，不能据此推断每个公司必考 |
| ORIGINAL | GPT 按知识点**原创**的模拟题/示例 | 明确写“原创模拟题，非公司/国考真题”，检查题意与答案一致 |

## 2. 关键可信资料（截至 2026-10-09）

- **2026 年国考公共科目笔试大纲**，国家公务员局原文转载：<https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml>。行政职业能力测验涉及政治理论、常识判断、言语理解与表达、数量关系、判断推理和资料分析。企业认知测评通常并不涵盖全部国考模块。
- **北森人才测评官方说明**：<https://www.beisen.com/product/evaluation/>，说明认知能力、个性、胜任力等测评用途；不说明某个求职者该如何刻意伪装。
- **北森一般个性测评设计介绍**：<https://www.beisen.com/res/885.html>，涉及大五人格与迫选等设计；不应整理“最优人格假答案”。
- **牛客一手求职复盘：2026 届机械秋招**：<https://ac.nowcoder.com/discuss/1605535?type=0>，作者谈到公司测评中存在类似行测的逻辑/图形/资料与职业性格题。这是**一个求职者经验，不是全行业题型保证**。
- **牛客面经案例（不同届别仅供研究）**：<https://www.nowcoder.com/enterprise/25552/interview>。机器人 C++ / Linux / ROS2 的技术面试需要核对原帖作者和时间；二手汇总不冒充实锤。

## 3. 每日卡标准

字段：`id / 日期 / 来源等级 / 原帖时间/URL / 适用岗位 / 知识域 / 题目是否原创 / 题目 / 自己的答案 / 分步解法 / 最快正确思路 / 易错点 / 限时建议 / 下次复习日期 / 实际掌握状态`。

一个模式在不同题型和来源中重复出现，才能称为“高频”；一份帖子只是例证。

**注意版权**：优先围绕同一知识点自行改写生成全新情景和数据，切勿简单替换数字而复刻付费或完整受保护试题的独创表达。

## 4. 训练成绩怎样记录

- 题目的**标准答案/模型示范**和**用户实际提交的答案**分栏保存。
- 只有用户提交回答后才标记 `PASS / REVIEW / WRONG`；没有证据统一为 `NOT_ATTEMPTED`。
- 性格测评只记录用户自愿分享的准备经验，不记录或评判私密人格标签，不提供伪造人格模板。
- 比较效果用近期限时完成率、错误原因和复习间隔，而不是编造全网通过率。

## 5. 每天应答要求

1. 读取此文件 + `LEARNING_STATE.md` + 最新题日文件。
2. 搜索最新公共来源；记录新增原始链接和截止日期。若搜索不可用就明确说，并可以用已有内容出原创题。
3. **每日学习目标约20题/60–120分钟**，可默认每组5题、约4组，逐题批改、先答后公布答案；每日**推送正文**仍可只展示一个待答题或首组入口，但不得将“每日仅一道题”当作当天完成量。详见 [每日执行协议](DAILY_STUDY_EXECUTION_PROTOCOL.md)。
4. 每天至少推进一项ROS2/项目或求职动作，只有真实证据才记DONE；每周总结并调整题型配比，不让行测占满机器人主课与求职准备；到时间强制收尾。
