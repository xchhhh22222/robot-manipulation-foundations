# 求职与学习复盘模板｜事实驱动

用于事件后、每周和每月复盘。**本文件是空白模板，不代表用户已有求职统计或已完成练习。** 参考 [执行规范](APPLICATION_AND_RESUME_EXECUTION.md)。

## 单次复盘记录

- 日期：YYYY-MM-DD；类别：EVENT / WEEKLY / MONTHLY。
- 路线：贵州国省考与事业编 / 贵州央国企与运营商 / 一线新一线研发企业 / ROS2机器人主课。
- 真实事实：哪条公开JD、实际考试/代码运行什么结果、官方反馈、实际耗时、必要的匿名证据；未知必须写 PENDING，不得推定被拒。
- 差距：是否符合硬性条件、有没有获得真人面试；若是做题则记录正确率/耗时/理解错误；项目记录运行验证。
- 原因假设：学历条件、学校筛选、岗位关键词、项目独立证据、测评成绩、技术知识、笔试时间管理、岗位名额或仍待流程。**每条假设标记证据或待验证，不擅自定性。**
- 最多三个改进动作：写明下一步动作、成功验收条件和复查时间。
- 下次复查：有什么变化？没有数据就保持 NOT_MEASURED / NOT_ATTEMPTED。

## 触发时机

- 每次真实测评、笔试、面试、申论批改或机器人实验后**当天/下次交谈**简短复盘。
- 每周看各轨道真实职位机会、测评推进、真人面试、技术与申论错题；确定下周1到3个动作。
- 每月分别复盘贵州体制内/央国企与一线新一线研发企业的岗位数量、简历版本效果、真实通过率与重点课程资源。
- 发现几十个已充分匹配、过正常处理期的岗位依然零面试，或同类笔试/面试问题连续失利时，立刻专项排障，**不要等到月底**。该数量只是诊断参考，不是招聘统一标准。

公开GitHub只存**匿名、可公开、证据充分**的复盘和聚合结果；个人实名投递记录、面试中保密问题、企业内部资料与完整版简历不可公开。
