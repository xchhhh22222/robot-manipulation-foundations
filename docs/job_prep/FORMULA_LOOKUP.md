# 资料分析：题干关键词 → 公式速查卡

> 更新：2026-10-10；用于国考、省考、事业编资料分析。先审问法，再找分子和分母。每道题先圈出“部分/整体、现期/基期、增长量/原值”。

## 一、抓分母比死背公式更有用

设整体基期为 T0、现期为 T1；某领域基期为 A0、现期为 A1。
整体增量 ΔT = T1−T0，领域增量 ΔA = A1−A0。

| 题干问法 | 分子 | 分母 | 结果单位 |
|---|---|---|---|
| 总体同比增长多少% | ΔT | T0（总体基期） | % |
| 该领域自身同比增长多少% | ΔA | A0（领域基期） | % |
| 领域**增长贡献率** | ΔA | ΔT（总体增长量） | % |
| 领域**拉动总体增长**多少个百分点 | ΔA | T0（总体基期） | 百分点 |
| 领域本期**占总体比重** | A1 | T1（同年总体） | % |
| 领域基期占总体比重 | A0 | T0（同年总体） | % |
| **比重提高/下降几个百分点** | A1/T1 − A0/T0 | 无须再除 | 百分点 |
| **比重相对原来增长多少%** | (A1/T1) − (A0/T0) | A0/T0（旧比重） | % |
| 是基期的**几倍** | A1 | A0 | 倍 |
| 比基期**多几倍** | A1−A0 | A0 | 倍 |
| 平均每单位数值 | 总量 | 单位数量 | 如万元/项 |
| 平均数同比增幅 | 现期平均数−基期平均数 | 基期平均数 | % |

**判断三连：**
- “自己涨了多少” → 领域增长量 ÷ 领域基期。
- “贡献了全部新增的多少” → 领域增长量 ÷ 总体增长量。
- “把总体增长率拉高了几个点” → 领域增长量 ÷ 总体基期。

## 二、Q031–Q032真题型模拟数据校验

2025→2026研发经费（万元）：
- 智能装备 2400→3000，Δ=600
- 人工智能 3600→3900，Δ=300
- 生物医药 4000→5100，Δ=1100
- 总体 10000→12000，Δ=2000

| 题干 | 算式 | 答案 |
|---|---|---|
| 总经费同比增幅 | 2000/10000 | 20% |
| 生物医药自身经费同比增幅 | 1100/4000 | 27.5% |
| 生物医药增长贡献率 | 1100/2000 | 55% |
| 生物医药拉动总经费增长 | 1100/10000 | 11个百分点 |
| 2026年生物医药占总经费比重 | 5100/12000 | 42.5% |
| 2025年生物医药占总经费比重 | 4000/10000 | 40% |
| 生物医药比重变化 | 42.5%−40% | 提高2.5个百分点 |

**自检等式：** 贡献率55% × 整体增长率20% = 对整体增长率的拉动数值11个百分点。智能装备拉动6个百分点，人工智能拉动3个百分点，生物医药拉动11个百分点，加总20个百分点，与总体同比增长率20%数值一致。

## 三、常见题目陷阱

- **% 和百分点不是同一个单位。** 24%→25% 是“提高1个百分点”，若问占比自身相对增长率则是 1%/24%≈4.17%。
- **增长贡献率**和**拉动总体增长**的分母不一样：前者是总体增长量，后者是总体基期。
- **同比**与上年同期比，**环比**与上一统计周期比。
- **单月值**如仅有累计量，先做：1—6月累计 − 1—5月累计。
- **总额增长不意味着平均数或比重增长。** 平均数要除项目数，比重要除同年总量。

## 五、Q033：总量增长与平均数增长区别
- 看到“总体经费同比”→ (总经费现期−总经费基期)/总经费基期。
- 看到“平均每个项目经费同比”→ 先求各年总经费/各年项目数，再求这两个平均数的增幅；也可用 (1+总经费增幅)/(1+项目数增幅)−1。
- Q033示例：2025经费10000、项目250；2026经费12000、项目255。总经费增长20%，项目数量增长2%，因此平均数增长1.2/1.02−1=17.65%，不是20%。
- 若总经费和项目数同时增长，平均数增幅可以小于总经费增幅；做题必须先核对“平均/每个/人均”的分母。


## 六、Q034：同一比重的两种变化问法
- 先求现期和基期占比：精密制造2025占比2800/10000=28%，2026占比3750/12500=30%。
- 问“比重提高/下降**多少个百分点**”→30%−28%=提高2个百分点。
- 问“比重本身**相对原来增长百分之几**”→(30%−28%)/28%≈7.14%；须再除以**基期比重**。
- 题中“总投资增长25%”与“精密制造投资金额增长约33.93%”均非比重相对增长率。比重变化先看正负号，再分辨是否需要再除旧比重。
