# 2025国考版《强化练习题》（上册）四分册对照审查｜2026-10-12

## 审查结论（只审核资料本身，不等于学生做过）

- 用户本轮上传四个**2025版《强化练习题》（上册）**PDF，分别为言语38 PDF页（印刷3—38）、判断31 PDF页（印刷41—69）、数量资料24 PDF页（印刷73—94）、申论45 PDF页（印刷97—139）。
- 与先前四册**《笔试系统讲义》（方法精讲）**的关系：方法精讲是**教方法+分题型例题**，强化练习是**按“四组练习”集中出现各地历年题与材料**，不是额外一本完整速算/推理“理论强化课”。
- 本轮逐页结构/文本核验没有在上传的四个分册中发现统一“参考答案”“答案解析”章节。**配套答案可能在另册，当前未提供，不能冒称题后有官方答案。** 逐题批改若需精确标准答案须自行审算，并标出有无权威答案依据。
- 很多题源标“国考/联考/省考/事业单位/网友回忆版”，**不是同一年、同类别的一套完整国考试卷**；部分标“网友回忆版”，与正式真题/权威答案的证据级别不同。
- 本轮仅发生**材料审核及索引建库**，未发生任何用户强化题实答。所有练习`NOT_ATTEMPTED`，不得记为正确或达标。

## 基础讲义与强化练习的实际差别

| 维度 | 基础讲义（之前上传） | 本次强化练习（上册） | 对教学的含义 |
|---|---|---|---|
| 组织 | 方法精讲，附思维导图、公式和示例 | 四轮`强化练习题（一）（二）（三）（四）` | 方法卡来自基础；题源索引来自强化 |
| 单题任务 | 知道关键一步和适用条件 | 无提示地识别方法、排除干扰项 | 迁移测试不等于新增一套理论 |
| 真题成分 | 方法说明+标注来源的例题 | 多地历年客观题或主观材料，混合国考/省考/事业题 | 做题时标注试卷类别，不能当作统一国考真卷 |
| 计时 | 教学阶段可不限定一分 | 可在掌握入门后逐步限时 | 不用未学过的方法强制提速 |
| 讲解证据 | 教材直接讲解章节较多 | 当前四册未检出成套答案解析 | 自己讲解的正确性和权威标准答案严格分开 |
| 整卷代表性 | 不是独立整卷 | **按学科切分的四组训练题，也不是完整120分钟国考卷** | 12月末—1月尝试整卷识别流程，之后逐渐做分类限时模拟 |

## 四册分科审查

### 1. 言语理解与表达｜PDF 38页，印刷3—38页
- 4轮练习：Ⅰ印刷3—12页**26题**；Ⅱ13—22页**26题**；Ⅲ23—31页**28题**；Ⅳ32—38页**28题**；文本题号合计**108题**。
- 前两轮主打中心意思、标题概括、文段意图等片段阅读；第三轮包含语句排序、逻辑填空；第四轮以词语/逻辑填空为主。具体题型以题干逐题验证；不是按难度由易到难的严格量表。
- 与基础《言语理解与表达》的6讲：中心理解、行文脉络和细节、语句表达、词语辨析一一对应。Q039仅B答案正确尚未展示思路，强化时从第一轮先抽相似**新情境**题，请用户指出转折/主题词和排除理由，不只要字母。
- 目前建议：10月日常20题中的言语份额，用强化1—2道逐步替换基础自创题；11月才安排同组5—10题连续计时。

### 2. 判断推理｜PDF 31页，印刷41—69页
- 4轮：Ⅰ41—48页**20题**（图形规律、空间展开）；Ⅱ49—57页**25题**（立体空间前几道+定义判断）；Ⅲ58—61页**24题**（翻译推理/排列+类比）；Ⅳ62—69页**22题**（削弱、加强等论证）；顺序按文本题号合计**91道**。
- 强化组中图形/立体题**不能只读PDF文本抽取**，必须看到原图与A—D选项，必要时读取用户PDF页面图。抽取文字里缺图≠无题。
- 与基础《判断推理》8讲对应；Q040逆否选C正确但没给独立推导，第一优先练Ⅲ印刷58页的“只有…才…”等，练`文字→逻辑关系→逆否/排除`；图形题逐步加入，不能长期只练条件推理。

### 3. 数量关系与资料分析｜PDF 24页，印刷73—94页
- 4轮：Ⅰ73—78页、Ⅱ79—85页为**长材料、表格/图形、连续多问的资料分析**；Ⅲ86—89页**20道数量运算**；Ⅳ90—94页**20道数量运算**。
- 与基础《数量关系与资料分析》8讲（资料4、数量4）互补：基础先教截位直除、分数比较、比重、平均数和工程赋值；强化要求同时提取长材料、选计算式、按选项截位、比较和检查单位。
- 与用户当前真实错点的**最紧密桥接**：
  - **Q037：方向、占比、百分点** → 强化Ⅰ印刷**75页、第二篇第4题**：比两海区氨氮占总氮之比重的百分点差。只建题目来源索引，具体原题仍留原PDF，不在公开GitHub转录。
  - **Q038：平均数增长/每单位** → 强化Ⅰ印刷**75页、第二篇第1/3题**（每排口量/多倍比较）与基础平均数方法卡连接；此处不应误记为“平均数同比增长率”同一种问题。
  - **Q041：已完成/剩余工作量混淆** → 强化Ⅲ印刷**87页第9—11题**的合作工作量/效率变式；**2026-10-13或之后实际到期复习**时再用，不再当日R2。
- 训练建议：10月起一次只给**同一个材料的1—2道**或一小组，不强制在没有公式熟练度时一次性整篇限时；11月合并成整篇5题定时并记录检索/计算/审题错误。
- 风险：这册是主题强化，不等于120分钟全套行测；资料练习有图表必须以原图核数字，不可靠OCR错误绝不灌入方法卡。

### 4. 申论｜PDF 45页，印刷97—139页
- 4轮：Ⅰ97—103页**4组材料题**（概括具体做法、提出对策、比较分析等）；Ⅱ104—110页**4组**（词句解释、综合分析等）；Ⅲ111—116页**4组**（如参评材料等实务应用文）；Ⅳ117—139页**3组较完整的综合材料与写作练习**。
- 与基础《申论》7讲对照：基础要点提取→单一题→综合分析→公文→文章写作；强化从**有完整材料、有分值、有作答身份、有字数限制**的题目验证写作能力。
- 例：强化Ⅰ印刷**97页**“乡村文化资源吸引游客”的15分/200字材料小题，可先用于初次申论练笔；强化Ⅳ印刷**124—125页**含2023贵州A的**1000—1200字**文章写作和不同字数/分值小题，**不适合现在零基础每天硬做整卷**。
- 建议10月工作日**每周可选一小题**，从“题干要什么→材料找3—5点→条理化表达→字数控制”循序做；11月适量纳入综合题、实务文；12月阶段目标仍是**行测120分钟整卷能力**，申论另设独立成长指标，不混作120分钟。
- 不把国考申论、贵州事业单位综合应用能力或省考申论当同一套评分细则。

## 真正强化的判定标准（学习状态而非纸面做题量）

- **教学刚解锁**：用户能说出解题第一步；`EXPLAINED`，非掌握。
- **独立强化成功**：不看讲解写出选择依据/申论材料证据；记`METHOD_VERIFIED`或`ANSWER_PASS`，方法和答案分开。
- **限时迁移**：不同材料中独立做对，且时间真实测量；`TRANSFER_VERIFIED`+时间；没有计时`NOT_MEASURED`。
- **整卷流程**：按[2026—2027长期计划](CIVIL_SERVICE_FOUNDATION_TO_2027_AUG_2026-10-12.md)进行真正完整国考行测卷；一套学科强化练习不能代替整卷实测。
- 一种旧错点**最多一次即时纠正题**，再错排T+1/T+7并等待用户答，避免被单点卡住八小时。

## 强化练习的正确使用顺序（2026-10-12用户纠偏，覆盖旧12月整卷进度）

| 阶段 | 强化资料怎么用 | 暂时不做什么 |
|---|---|---|
| 2026年10—12月：**基础覆盖优先** | 主要跟随基础讲义29讲和独立方法MD卡；仅穿插少量已经学过知识点的强化题，验证能不能迁移 | 不强制每天替换5—8道强化题，不强推限时整卷 |
| 2026年12月末—2027年1月：**不限时整卷入门** | 将整卷作为题型辨认/解题流程诊断；允许跨工作日分段，遇到知识卡缺口再补 | 不把填满选项当成无卡壳，不要求120分钟 |
| 2027年2—3月：**准确率强化** | 按错误知识点选强化真题，分模块反复迁移，但同错点当堂R1上限不变 | 不先学刷题速度套路再补理论 |
| 2027年4—6月：**速度与套卷** | 先专项计时，再半卷、完整分类卷逐步限时 | 不跨贵州省考/事业A/B/C套错模板 |
| 2027年7—8月：**考试水平验收** | 依据真实试卷分类、正确率趋势、用时与作答完整度评估 | 不承诺100%正确率或已获报名资格 |

## 尚缺/风险
1. 此前2025国考版方法精讲与本强化上册都不能充当**2026官方六块行测的全套政治理论/常识判断**专项，已有独立缺口索引。
2. 强化上册按学科分册，**未提供官方整卷答题卡、统一限时安排、答案解析册**。需要另选合法可用的真实完整类别试卷。
3. 标“网友回忆版”的题不可被冒称绝对核准的官方真题、答案需单独核对。
4. 原PDF是用户给定教学文件，只供当前可访问的附件读取，**没有公开上传**；以后不能假设新对话天然可再读这几个附件。公开仓仅放本审核、页码索引和自写技巧，避免批量传播商业教材原文。
