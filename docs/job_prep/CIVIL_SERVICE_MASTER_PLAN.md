## 1. 第一目标：2027年1月整卷独立入门

到2027年1月，面对一份没有做过的完整行测试卷，主要题型已经接触过代表题，能够独立识别题型、选择适用方法、写出可执行的第一步，并独立完成整卷作答；申论同步达到能审题、定位材料、组织答案并完成一份分段整卷的入门水平。计划2027-01-29做阶段验收。

“题目都见过”指**主要题型见过，不是提前做过验收原题**。认识题型、选对方法、计算正确、限时完成分开统计。第一目标不要求先达到正式考试限时或全对，也不把任意未来试卷所有冷门知识都已掌握当作承诺。政治/常识须记录实际知识依据或有根据的排除；不认识考点、蒙对、经提示完成都如实列缺口，不能当成方法已掌握。

### 验收办法
- 12月底根据[29讲覆盖表](methods/FOUNDATION_COVERAGE_CHECKLIST_2026.md)检查遗漏，不能以卡片数量代替覆盖。
- 1月选择题目完整、图形可读、答案可核查、未用于此前教学的贵州省考行测卷；材料不满足要求时选对应类别国考卷。选择结果记录年份、类别、来源、完整性、是否接触过。不冒称未来报名资格。
- 01/11—01/15用整卷A分科跨日独立作答，全部提交前不讲解本卷、不提供公式；01/18—01/22只修复真实缺口；01/25—01/29用不同整卷B复验。

### 2.0 两阶段切换及进度定义（V2.3覆盖V2.2旧复测先行）
- **BFS第一轮**：对每讲及其核心子技能核查旧证据，未学的优先简要解释、方法入口和**至少1道真正独立尝试的代表题**；答错只给必要纠正、记录错因/风险，随后转下一个子点，不为一题机械再测到PASS。已经接触但有明显未教子点，也属于本阶段的待覆盖，不可因章名已见就直接算完整。
- **BFS完成门槛**：29讲每讲核心子技能达到`FIRST_PASS_COVERED`（看过/讲过+有代表题的学生真实首答；不能只有教师讲稿）；整讲仍有未知子点则`PARTIAL_COVERAGE`而不是完成。政治/常识和申论实际产出不从29讲中隐去。每周报告新增覆盖节点、仍未覆盖节点，答错不影响继续前进但保留清单。
- **强化DFS**：仅在完成第一轮覆盖、或用户明确切换时，集中取旧队列和本阶段错题依概念依赖、错误频率、考点重要度排序，进行T+7/错题重测、综合迁移及方法纠正；不把过去到期窗口自动变成PASS，也不一次性积欠旧卡。之后按原计划选未见整卷验收。
- **时间建议**：争取在2026-12-18前大体完成29讲第一轮主要范围，12/21—2027-01/08争取集中强化；若仍有缺口，优先如实列出并利用正常课表补，不因目标日期伪造已学。01/11—15卷A、01/18—22修复、01/25—29卷B的里程碑仍保留，安排以真实覆盖情况动态调整。
- **BFS期复测政策**：以前标定的11/17图形、11/18三集合+主旨、11/19抽屉、11/23词句解释等T+7节点**统一状态`DEFERRED_BY_BFS_POLICY / NOT_ATTEMPTED`**，保留原计划日期与原题错因，等DFS统一调度。除新方法讲解所必需的简短检查外，不每日固定清空到期卡、不周五重复整套强化题。

### 2.1 新课准入闸门：先判“没学过”再教学

**从V2.2起，任何内容被称为“新知识/新课”前，教师必须先完成四源核验：**
1. 最新[29讲覆盖与剩余清单](methods/FOUNDATION_COVERAGE_CHECKLIST_2026.md)；
2. 最新[学习状态](LEARNING_STATE.md)；
3. 最新[复习队列](SPACED_REVIEW_QUEUE.md)；
4. 最近一次同模块daily/领域原始课堂。

核验后把当天拟讲子点只分成三类：
- **NEW / 未学**：没有真实教学或代表题证据，才允许按“概念→识别条件→方法→坑点→例题”完整新授。
- **REVIEW_OR_TRANSFER / 已学未稳**：已经讲过、做过或有局部正确证据，只允许先给无提示新情境；答对就迁移前进，答错只补失败的那一小段，禁止从头重讲。
- **CLOSED / 已通过**：正式复测已PASS或已有足够独立迁移证据，不得包装成新知识；只可在综合材料、周五混合或后续方法的必要前置中短暂调用。

**硬性防重复规则：**
- 课表写了某个主题，不代表该主题所有子点都是新课；必须以覆盖表的“剩余未覆盖/待验收”列决定真正新授内容。
- 若某主题包含“已会＋未会”，只讲未会部分；例如贡献率已PASS时，后续“贡献率/拉动/倍数”课只能把贡献率当迁移，真正新授拉动百分点、倍数/多几倍等缺口。
- 用户明确说“这个学过”时，立即停止当前新授表述，先核证据；核实后改成迁移/跳过，不为了完成课表继续重复。
- 若证据冲突或旧记录不够清楚，默认标`STATUS_UNVERIFIED`，先用一道无提示诊断题确认；**不能因为不确定就按零基础重教**。
- 每次收官后同步覆盖表；下一次开课只从“剩余未覆盖/待验收”清单取新内容。

### 2.2 2026-11-25批准：申论底层能力专项训练（V2.3内嵌）

用户根据11/23—25真实作答提出解决审题漏答、材料证据、语言精炼、公文结构的问题，对三阶段方案明确回复“可以”。详见[申论专项训练执行细案](methods/ESSAY_SKILL_TRAINING_2026-11-25.md)，从下一工作日申论开始。

每日申论仍在原时间预算：五步“拆题→定位材料→提炼关键词→按槽组织→自查”。阶段A专项拆解建议3—5工作日，B组合建议5—7工作日，C未见材料独立验证；按真实作答达标切换，不按日期自动PASS。首答前先让学生独立拆任务，不由教师预填答案；证据、字数、结构、提示等级分开记录。申论允许针对这些底层能力做分步训练，同时推进新题型；**行测BFS、旧T+7延期、原周末休息、每日120分钟及1月整卷目标不变**。专项阶段不等于全科切换DFS，不另建强制复测作业或定时提醒。

## 3. 周五执行方式：BFS期继续开新课

广度遍历期间，周五不再强制安排四科混合强化或先清到期卡，而是作为**跨模块未覆盖节点的机动新课日**，优先补本周未能首次教学的判断/言语/资料/数量核心子点和申论新题型。只保留一次极短的本周新知识脉络整理，记录实际作答；不能把未学主题叫复习。完成首轮覆盖后，周五恢复混合迁移与错因修复，但不要叠加第三套作业。

## 4. 复习记录与证据（BFS/DFS分期）

- BFS期每日开始**不再强制15分钟T+7**；旧复习队列只是历史证据与未来DFS任务池。每个新节点以`NOT_COVERED → FIRST_PASS_TAUGHT/ATTEMPTED → FIRST_PASS_COVERED`追踪，未独立完成过代表题保持`PARTIAL_COVERAGE`。当堂错误标`WRONG / NEEDS_DFS_REVIEW`，不追着原题反复补到对；不得篡改原答。
- 每周新增独立**复习卡**不再有“必须建卡”的目标（原上限5仅适用于旧模式，BFS期可按方法簇归并记录任意真实已学节点，避免30多张机械卡）。不以卡片数量表示已学；未来DFS汇总错点复测，最多每日2—3张/约15分钟的旧规则只在DFS重新启用或用户要求时适用。
- BFS期知识点教学节奏以具体难度和用户作答为准，原则上**每个工作日至少推进一个真实新子知识点，有余力再进入下一个**，而非每日只学一个旧模块。每题先由用户给独立首答再纠错，知道错因后继续前进；不要把老师提示后的答案当独立PASS。
- 用户可随时要求对重要方法立即回顾，但除用户指定外不重新启用按T+7强制教学。在正式切换前所有原未做正式卡仍标`NOT_ATTEMPTED / DEFERRED_BY_BFS_POLICY`，并保留原到期日；已PASS记录不倒改。
- 到2027年1月整卷仍分别记录识别率、方法选择、独立正确率与实际时长（未计时则`NOT_MEASURED`）。保留隐私和课程证据边界。
