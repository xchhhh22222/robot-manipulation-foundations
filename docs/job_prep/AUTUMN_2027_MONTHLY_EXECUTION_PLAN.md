## 0. 判断：时间是否足够、何时必须转向

- **两个截止点**：
  - 2027-03-31：有可复现、可讲解的机器人/工业软件个人成果 + 可据真实证据调整的A/C或相关简历初稿，具备申请符合届别的实习基础。
  - 2027-06-30：主要项目/简历/笔面试已准备到可投递，不再以“继续学完全部Day”为由推迟招聘；2027-07起每日/每周核对**2028届**提前批岗位开放、截止与资格。
- 依据：美团2027届于2026-08-17开始网申（https://zhaopin.meituan.com/web/campus/schedule）；普渡机器人2027届招聘与2028届实习曾在2026年6月同步开放（https://job.hust.edu.cn/zpinfo1/2406953.htm）；教育部2027届金秋招聘于2026-09-17启动（https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202609/t20260918_1451304.html）。这些是历史时间参照，不代表2028届必定同日。
- **实习不必等到2027年**：若当前/后续2028届实习岗位确实开放且用户满足时间、地点、专业条件，早于2027年也可以申请；当前2027届正式应届岗位**不得**当作用户2028届可投职位。
- 两条就业轨道独立：贵州优先的公务员/事业编/央国企/运营商/银行等公共及稳定渠道；一线、新一线的机器人、工业C++、工业软件、视觉AI/具身企业研发岗位。2028年度国考与2028省考资格和时点以届时公告为准，不能把在读非应届学生视为当前合格考生。
- 学业和毕业必要研究任务是硬约束，不为了刷题/项目进度破坏学校任务、实习合规或人身健康。

## 3. 固定复盘日历与自动提醒分工

- **每日早上约08:00（北京时间）**：既有每日任务给“20题的分组计划+到期复习入口+当日项目或求职一项行动”；不把提醒中的计划当完成。
- **每周五19:00（北京时间）**：每周任务，20–30分钟：本周行测实际题量/耗时/错因、机器人真正通过的构建或测试、核实的JD、下周1–3件优先事项。周末不安排例行复盘。
- **每月第一个工作日早上约08:00（北京时间）**：月复盘自动任务查看上一自然月的记录并提出本月最多3个可验收目标；建议当天45–60分钟精读。首期**2026-11-02（周一）**回顾2026-10-10至10-31（首期数据可能只有工作日作答）。
- **重要检查日期（工作日）**：2026-10-30（周五）首次节奏检查；2026-12-04（周五）八周实验；2027-03-31（周三）实习准备门槛；2027-06-30（周三）秋招就绪门槛；2027-07-15（周四）提前批监控；2027-08-31（周二）、2027-09-30（周四）、2027-10-29（周五）招聘阶段复盘。历史计划2027-10-31为周日，因此常规复盘提前到10-29。
- **事件驱动**：真实JD截止、筛选失败、真人面试、项目运行卡住或重要论文/毕业节点，不必等月末才调整。
- 任务运行不保证设备推送到达；如用户通知设置尚未开启，应在ChatGPT设置中开启；提醒可能不自动出现在最新聊天窗口，跨对话按GitHub文件衔接。

## 4. 每次月复盘需要回答的5个判断题

| 看板 | 必须用到的证据 | 重点决策 |
| --- | --- | --- |
| 行测与公考 | 实际作答数、用时（如有）、分题型正确率、两次新数据复测、申论/综应真实练习 | 是否调整题型配比？是否还需基础题，还是应该提高限时练习？ |
| 机器人/软件工程 | 最新可构建文件、测试或控制器/Action结果、Git SHA、Bug与独立责任范围 | 本月产生可复现成果吗？是否需要压缩范围到最小闭环？ |
| 企业研发就业 | 真实JD样本、岗位合格条件、技术技能差距、实习/校招申请阶段 | A/B/C简历与岗位需求对得上吗？机器人方向是否过窄？ |
| 贵州公共岗位 | 国考/省考/事业/央国企的官方公告、硕士085404和本科080910T专业资格逐条核对 | 公考和职业测评投入是否合理？是否应增加申论/综应占比？ |
| 生活与毕业 | 每周真实投入时间、疲劳超时、论文/研究/毕业约束 | 总时间是否超过可持续范围？是否该减题、暂停低回报分支？ |

**决策规则**：
1. 连续两个自然周没有可复现技术产物，先查是否真实投入与外部阻塞；有投入仍无突破，则缩小实验，而不是再开新大项目。
2. 连续两轮限时题组同类错误重复，安排T+1/T+7迁移而非当天无限纠错。
3. 2027-03-31如不具备实习申请材料，立即把4月优先级改为最小项目证明+可投简历，减少无关课程。
4. 2027-06-30如岗位简历/技术叙述未就绪，7月优先修最影响申请的短板；**已经开放的合格职位不因等项目完美才投**。
5. 进入真实招聘窗口后，申领/截止/笔试/面试优先于机械完成每日20题。

## 5. 数据准确性

- 只能记录用户实际完成和公开可核查的职位；计划用 `PLANNED`，等待用户行动用 `PENDING_USER`，缺少计时或投递结果用 `NOT_MEASURED`。
- 项目仓库实时提交状态必须另取Git/运行证据，不能因为路线文档写了目标就改成PASS；不得公开完整简历、个人申请/联系方式、企业商业或客户数据。
- 月度文档更新须fetch最新SHA、增量合并、提交后重新fetch验证；GitHub是匿名公开进度源，不等于跨聊天自动记忆所有信息。
