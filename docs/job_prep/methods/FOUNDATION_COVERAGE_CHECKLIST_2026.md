# 2026年12月“基础全部学完”课程覆盖清单（贵州优先）

> 2026-10-12建立。**只列课程内容覆盖要求，不记录虚假的学习完成**。本页的“学完基础”指基础课程模块至少被解释过、能判断典型题型和第一步，并有真实尝试证据的优先；并不是全部练习高分或限时达标。原教材课程数量来自用户上传《2025国考版笔试系统讲义》，具体章节内的知识卡依据做题进度再拆。

## 状态口径

- `INDEXED` = 课程提纲或教材目录已核对，**不代表用户学习**。
- `PARTIAL_EXPLAINED` = 课程中若干小点已讲解，但**整讲未完成**。
- `LECTURE_EXPLAINED` = 该讲所有主要基础方法已经过一次系统讲授/识别训练（仍不等于用户会做）。
- `USER_ATTEMPTED` = 用户有独立作答证据，但不表示整个讲的掌握程度。
- `METHOD_VERIFIED / TRANSFER_VERIFIED / TIMED_VERIFIED` = 分别需能自行解释、变题独立用、真实计时达标的证据。
- 初次建库这29讲（数量8、判断8、言语6、申论7）绝大多数只`INDEXED`，**不能因为先前创建9张小卡而将整讲标已学完**。
- 每个讲义单元可继续拆多个小MD卡：`methods/cards/<method-ID>.md`，并在本清单内链接；每天只更新已真实碰到的条目。

## 12月底验收如何操作

1. 检查29个基础教学单元是否至少达到`LECTURE_EXPLAINED`，并核实关键题型是否有用户亲自做过的代表题（记录`USER_ATTEMPTED`，答错也计“经历过”，但不算掌握）。
2. 若每天只能投入行测60分钟，**覆盖29讲+政治常识+申论与贵州事业差异可能超出可用时间**。先保证主要知识都认识、说明还没深入的次级点；不足就如实延续到1月，不用“100%完成”掩盖缺口。
3. 完成基础教学后，12月底—1月再尝试不限时或分段整卷，记录`题数 / 看懂与否 / 会下手 / 独立答题 / 提示 / 猜测 / 真正卡壳 / 总耗时`。
4. 错题仍遵守“同点即时只补一题、T+1/T+7工作日复习”；绝不以建卡或老师讲过替代用户自己的证明。
