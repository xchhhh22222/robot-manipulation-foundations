# 数量关系与资料分析｜逐题方法卡

教材：《数量关系与资料分析》（2025国考版），印刷页150—213。这里是简明方法导航和真实做题证据，不是整本教材的转录。

## 已开始的方法

### QA-SPEED-01 截位直除（教材150—151页）
- **什么时候用**：比重、比例、基期量、一般增长率等出现不好整除的分式。
- **第一步**：先看题目问法和选项差距，再决定需要估算到什么精度；不要先猜答案。
- **做法**：单步除法通常先只截分母；多步再判断是否上下都截。选项较散可先试前两位，接近则保留前三位，结果接近边界时恢复原数验证。
- **风险**：不能把任意截位后的答案当精确两位小数；升降方向和百分比/百分点另行检查。
- **证据**：用户指出 Q037 无选项精确2位难以一分钟内算完，当前仅`EXPLAINED / INDEPENDENT_NOT_VERIFIED`。

### QA-COMPARE-01 分数比较（教材152—153页）
- **第一步**：先看有无一个分数“分子大且分母小”，可以直接比；其余再用同分子/同分母、同倍缩放或交叉比较。
- **应用**：比重方向看两年度的`部分/整体`谁大；优先判断方向，数值精算按选项要求进行。
- **证据**：Q037比重方向判断原答错，`REVIEW`，不能认PASS。

### QA-SHARE-01 现期/两期比重（教材171—178页）
- 识别：文中“占、比重、比例”→ `部分÷整体`；“比上年提高/下降多少个百分点”→ `新占比－旧占比`。
- **Q037旧题**：2025年94/214≈43.93%，2026年115/250=46%，所以**提高约2.07个百分点**（不是下降1%）。
- **适合入门的教学补充（不是教材原文公式）**：不用猜44%，先从50%出发：214的一半107，分子94比107少13；13/214≈6%，占比约44%。这只是“确定大致量级”的辅助思路；正式根据选项截位。
- **易错点**：`46%-44%`是约**2个百分点**；“占比相对增长率”则还要除以旧占比。单题计算难度要与选项精度匹配。
- **真实状态**：Q037 WRONG；Q037-R1尚NOT_ATTEMPTED；同错点只允许一题即时补救。

### QA-AVERAGE-01 平均数同比（教材179—182页）
- 总量/份数=平均数；两期平均数增长可用`（新平均数－旧平均数）/旧平均数`，或总量增速a和数量增速b：`(a-b)/(1+b)`（a、b用小数）。
- **Q038**：3600/90=40，5400/120=45，同比(45-40)/40=12.5%；用户仅提交“12.5”，状态`NUMERIC_PASS/METHOD_UNVERIFIED`，下一次需说明步骤。

### QA-WORK-01 工程问题：赋总量（教材198—200页）
- **第一步**：只给甲乙单独所需天数时，先取两者天数的公倍数赋给总工作量，使每天效率变成整数。
- **Q041-R1教师讲解**：甲15天、乙20天，总量赋60；甲每天4，乙每天3，合作4天完成28；剩余32，甲还要8天。
- **错误类型**：用户计算合作完成`7/15`正确，但误把已完成量当剩余量，最终7天错误。状态`ATTEMPTED_WRONG/PARTIAL_METHOD_PASS`；本轮不再出R2，隔日再测。
