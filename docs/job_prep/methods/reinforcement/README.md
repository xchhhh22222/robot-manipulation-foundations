## 当用户答题时的最小更新

- 当日`daily`记录：强化题索引ID（如`R-QD-I-P75-4`）/题型/开始结束时间/用户原始答案或主观文字/是否独立/批改依据。
- 若暴露新错误，只更新相关**一张方法卡**和复习队列；已索引的所有题不能批量标PASS。
- 如需要对照完整题目、表格、图形，**只读对应页图像**；如答案权威性缺失，在记录中标`ANSWER_KEY_UNAVAILABLE`，不得冒充书中标准答案。
