## 方法卡规则（以后每做题都按这个逐步补）

一张知识卡至少有：`方法ID`、题型/题干触发词、教材章节/页码、**看见题目后的第一步**、简明步骤、适用/失效边界、错误样例、真实题号、学习证据、下一次复习日期。无需一次填满，缺证据填NOT_VERIFIED/NOT_ATTEMPTED。

**状态严格分层**：
- `INDEXED`：只把教材目录收录进索引，**不代表已读懂**。
- `EXPLAINED`：已向用户讲过，**不代表掌握**。
- `ANSWER_PASS` 或 `NUMERIC_PASS/METHOD_UNVERIFIED`：有用户实答，但方法或时间尚未实证。
- `METHOD_VERIFIED`：用户可以独立列式、解释为什么选该方法。
- `TRANSFER_VERIFIED`：换情境仍能独立运用，且有可核验实答。仅凭讲解、观察例题或AI计算不升级状态。

## 工作日执行闭环

1. 沿用[日学习执行协议](../DAILY_STUDY_EXECUTION_PROTOCOL.md)：周一至周五行测60—120分钟、目标约20题，通常每组5题；时间预算比凑满题数重要。周末不补欠题、不派强制新任务。
2. **先做题→判错因→找到教材方法→揉碎讲明第一步→在同一错点最多补一道当堂纠正题**；纠错后不再R2、R3无限重复；到期T+1/T+7融入工作日正常题量。
3. 初学计算技巧先学可解释的步骤，再按选项差距决定精度；**不要求无选项题一分钟精算至小数两位**。方法速度需有用户计时证据才标达标。
4. 在对应分类卡中仅补**当日实际学到/暴露的问题**和对应题号；真实作答/复习证据写入[每日记录](../daily/2026-10-12.md)、[学习状态](../LEARNING_STATE.md)、[复习队列](../SPACED_REVIEW_QUEUE.md)。未尝试明确NOT_ATTEMPTED。
5. 每次新对话优先读[接力卡](../NEXT_CHAT_HANDOFF.md)和本索引，**不要重讲已核对的基础背景**；不要把“讲过”“做对一道”写成“稳定掌握”。
