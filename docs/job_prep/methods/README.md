## 一张方法卡必须有

1. **唯一ID和知识点**（不把比重、平均数、工程混成同一张长文）；注明教材印刷页和其他可靠来源。
2. “**看到题目第一步做什么**”＋可解释的步骤/公式＋方法的失效条件。
3. **一道自主编写的演示题与完整演算**（教学，不冒充教材原题/官方真题），关联已发布问题ID、用户原始错因和下次应测的点。
4. **状态**：INDEXED（仅建目录）、EXPLAINED（讲过）、ANSWER_PASS（题目答对）、METHOD_VERIFIED（独立讲清/列式）、TRANSFER_VERIFIED（新情境独立通过）等，不因为AI写好笔记就给用户记PASS。
5. 发生一次真实题目作答时，更新原题进度/错题队列；**一个错点即时纠正最多一道**，未解锁的知识可以延期；节省时间比累积卡片数量更重要。
