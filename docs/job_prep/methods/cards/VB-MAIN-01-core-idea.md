# VB-MAIN-01｜言语主旨：提问→文段→选项

- 来源：《言语理解与表达》（2025国考版）印刷页4—13中“中心理解”，自写摘要。
- 状态：Q039 ANSWER_PASS / METHOD_UNVERIFIED。
- 触发：“主要说明、意在强调、文段主旨”。
- **第一步**：先读提问确认是主旨题；再找主题词、转折/因果/必要条件与中心句。
- 方法：将中心句用自己的话概括一句，再检视选项：有无只说例子、偏离主题、无中生有、绝对化等。
- 自创演示：材料说“社区新增借阅点，但晚上很早关门，部分居民仍无法借书。提升阅读服务的关键是匹配居民实际使用时段。” 主旨应是改善开放时段与服务匹配，而不只是增加站点数量。
- 易错：把转折前背景、单一例子当主旨；“转折后重点”是线索，不是脱离语义的机械口诀。
- Q039答B正确，只有答案证据；再遇新主旨题要求说明一句依据。
