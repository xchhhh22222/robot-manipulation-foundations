# QD-SPEED-01｜截位直除：先看选项，再定精度

- 来源：《数量关系与资料分析》（2025国考版）印刷页150—151，第一章速算技巧；本文件为**自主归纳**。
- 状态：EXPLAINED / INDEPENDENT_NOT_VERIFIED；Q037暴露用户对“凭空猜44%”难以接受。
- 触发：资料分析中出现复杂除法，且题目多为近似选择题。
- **看题第一步**：找选项距离；选项相隔较大先尝试两位近似；距离很近则三位或原数核对。
- 方法：一步除法一般优先截分母，保持分子的主要有效数字；复杂多步按误差风险判断是否分子也截位。求比例要先确定最后是小数还是百分数。
- 自创演示：87 ÷ 211，选项如 31%、41%、51%、61%。把211近似为210，87÷210≈0.414，所以约41%，不需要完整长除法。
- **失效边界**：选项紧密、计算结果贴着选项中点、分母截位带来方向性误差时不能直接凭粗估选项。
- 关联：原Q037方向/百分点答错；Q037-R1仍NOT_ATTEMPTED，不能看演示即判方法PASS。
