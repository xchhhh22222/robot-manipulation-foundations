# QU-WORK-01｜工程问题：赋值最小公倍数

- 来源：《数量关系与资料分析》（2025国考版）印刷页198—200“工程问题”；自主归纳。
- 状态：Q041 WRONG，Q041-R1 ATTEMPTED_WRONG / PARTIAL_METHOD_PASS。
- 触发：甲做完需A天，乙做完需B天，合作若干天，余下由一人完成。
- **第一步**：先把“总工作量”假设成A和B的公倍数；求出甲乙每天各做多少。
- 顺序：**总量→每天效率→已完成→剩余量→剩余时间**。尤其不能把“合作完成量”误当成“尚未完成量”。
- 自创演示：甲16天、乙24天。赋总量48，甲每天3，乙每天2。合作6天做(3+2)×6=30，剩18，甲再做18÷3=**6天**。
- Q041-R1：用户已算出合作完成7/15，但误写成还需7天，真实还需8天；本轮已用完一个错点一次即时纠正机会，**不再R2**；2026-10-13、10-19间隔复习待答。
