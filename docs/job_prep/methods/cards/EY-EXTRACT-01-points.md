# EY-EXTRACT-01｜申论材料找要点：先看题，再找证据

- 来源：《申论》（2025国考版）印刷页218—220“要点挖掘技巧”；自主归纳。
- 状态：INDEXED / NOT_ATTEMPTED。
- 触发：“概括问题、举措、影响、经验启示”。
- **第一步**：圈定问的对象、材料范围、要素和字数限制，再回材料定位事实。
- 方法：摘取明确要点→归纳合并同类→必要时有据推导，最终每条可以指回材料。
- 自创示例：材料：“社区为老人设置线下帮办窗口，并将常见事项整理成纸质流程图。” 问：“概括方便老年人办事的措施。” 可概括为“设置线下帮办服务；提供易读的纸质指引”。
- 边界：示例只是教师展示；没有用户实际申论答卷或限时数据，不计通过。
