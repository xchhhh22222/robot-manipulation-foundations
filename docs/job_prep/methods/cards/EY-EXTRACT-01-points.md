# EY-EXTRACT-01｜申论材料找要点：先看题，再找证据

- 来源：《申论》（2025国考版）印刷页218—220“要点挖掘技巧”；自主归纳。
- 状态：`USER_ATTEMPTED / ANSWER_PARTIAL / TRANSFER_DUE`。
- 触发：“概括问题、举措、影响、经验启示”。
- **第一步**：圈定问的对象、材料范围、要素和字数限制，再回材料定位事实。
- 方法：摘取明确要点→归纳合并同类→必要时有据推导，最终每条可以指回材料。
- 找措施时优先圈动作词，例如“保留、安排、制作、组织”；题目只问措施时，不用大段复述问题和原因。

## 2026-10-27真实作答

课堂材料包含四项适老服务措施：保留线下人工服务窗口、工作人员一对一指导、制作大字版办事指南、组织志愿者定期上门。

用户独立提取到后一对一指导、大字版指南和志愿者上门三项，漏“保留线下人工服务窗口”；答案开头写入了老人不会使用智能手机、办理困难等原因。判定：`INDEPENDENT_ATTEMPT / ANSWER_PARTIAL / 3_OF_4_MEASURES_EXTRACTED`。输入中的“只能手机”“大直报指南”按上下文视为笔误，不算材料理解错误。

教师参考答案只供对照，不计学生成稿；当天不要求立即重写刷到正确。
