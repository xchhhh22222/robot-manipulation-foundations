# EY-SINGLE-01｜申论单一题：按要素分条概括

- 来源：《申论》（2025国考版）印刷页221—224“单一题”；自主归纳。
- 状态：INDEXED / NOT_ATTEMPTED。
- 触发：题干要求“概括做法/问题/影响”，且答案要素较集中。
- **第一步**：确定题干要“做了什么”还是“有什么问题/影响”，再分类。
- 方法：同类要点合并，**每条先写短总括词**，后加证据内容；不重复，不遗漏，不超字数。
- 自创演示：材料有“安排志愿者上门”“打通预约渠道”“设置满意度反馈”；若题目问措施，可概括为：①强化上门帮办；②优化预约流程；③建立服务反馈机制。
- 练习状态：尚没有用户提交的申论答案；工作日可建议每周一道小题，不强制在没给材料的情况下作文。
