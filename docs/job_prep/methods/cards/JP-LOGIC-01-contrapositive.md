# JP-LOGIC-01｜条件推理：先翻译，再逆否

- 来源：《判断推理》（2025国考版）印刷页114—121“翻译推理”；自主归纳。
- 状态：Q040 ANSWER_PASS / METHOD_UNVERIFIED。
- 触发：“如果…那么…、若…则…、只有…才…、可以推出/一定为真”。
- **第一步**：按原题条件翻译成A→B，确定A/B谁是必要条件。
- 口诀：**肯前肯后；否后否前；否前、肯后不能乱推。** 等价：A→B 等价于 非B→非A。
- 自创演示：“只有完成培训，才能上岗”：上岗→完成培训，因此没完成培训→不能上岗；“完成培训→一定上岗”不能确定。
- 易错：把必要条件当充分条件，或自行加上真实世界的设备故障例外。
- Q040：最终验收→完成安全测试，因此没做安全测试→不可能通过验收；用户选C正确，尚需新题检验能否独立写出逆否式。
