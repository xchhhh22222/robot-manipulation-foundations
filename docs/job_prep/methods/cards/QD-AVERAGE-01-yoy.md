# QD-AVERAGE-01｜平均数同比：总量增长不等于人均增长

- 来源：《数量关系与资料分析》（2025国考版）印刷页179—182，平均数；自主归纳。
- 状态：Q038 NUMERIC_PASS / METHOD_UNVERIFIED；尚未独立解释列式。
- 触发：“平均每个”“人均”“每单位”及其同比增幅。
- **第一步**：认出平均数分子是总量，分母是数量/人数；切勿直接使用总量增幅代替平均数增幅。
- 公式：平均数=总量/数量。设总量增长率a、数量增长率b，平均数增长率=(a-b)/(1+b)（增长率先用小数）。
- 自创演示：去年总量2400、项目60，今年总量3000、项目75，去年与今年都是40/项目；总量增长25%，平均数增长**0%**。
