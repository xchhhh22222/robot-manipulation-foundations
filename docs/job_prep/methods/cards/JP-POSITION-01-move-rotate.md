# JP-POSITION-01｜图形位置规律：平移与旋转分开观察

- 来源：判断推理图形位置规律课堂；2026-10-27教师自编图形练习。
- 状态：`USER_ATTEMPTED / PARTIAL / TRANSFER_DUE`。
- 触发：元素形状、数量基本不变，但位置或朝向连续变化。
- **第一步**：把“位置”和“朝向”分成两条线观察，不能把箭头朝向当成移动方向。
- 平移检查：向哪个方向、每次移动几格、是否循环或越界回到起点。
- 旋转检查：绕哪个中心、顺/逆时针、每次90°/180°或其他角度。
- 组合检查：分别写出“位置序列”和“朝向序列”，再合并得到下一幅。
