# 言语理解与表达｜逐题方法卡

来源：《言语理解与表达》（2025国考版）。教材方法精讲6讲，分片段阅读、语句表达、逻辑填空三大部分。

## VB-MAIN-01 中心理解（教材印刷页4—13及后续中心理解课程）
- **题型触发**：文段“主要/旨在/意在/重在”说明什么。
- **第一步**：按教材顺序`提问→文段→选项`，看提问确认要找中心而不是细节。
- **做法**：识别转折、因果和主题词，找作者主要观点；“但是、然而、实际上”等转折常提示后文重点，但仍须结合完整结构。
- **排除**：只重复解释性细节、文段没提到的推断、偏离中心主题、偷换对象的选项。
- **Q039**：公共服务数字化不是只增加入口而是打通流程、改善办事体验；用户选B正确，`ANSWER_PASS/METHOD_UNVERIFIED`，还没有独立说出依据和用时。
