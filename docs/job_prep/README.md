## 定位与边界

- 背景：2028 届双非硕士，现有真实工业机械臂系统集成/联调/测试实习经历，个人 ROS2 Jazzy + MoveIt2 课程处于 Day28 Pose Goal 实验阶段。实习项目具体商业源码与标定/设备参数不得上传；项目中自己做过什么、尚未完成什么要如实区分。
- **双轨地域原则（2026-10-09 用户纠正并确认）**：**公务员、事业编、央企/国企、运营商等优先贵州省内**，具体资格/岗位内容核验后省外作为补充；**机器人、工业软件、视觉、AI等企业研发岗优先一线/新一线城市**（如上海、深圳、广州、北京、杭州、苏州、成都、武汉、南京等，示例非封闭列表），不能将“贵州优先”错误地应用到民营研发岗位。见 [执行规范](APPLICATION_AND_RESUME_EXECUTION.md) 与 [岗位雷达](GUIZHOU_FIRST_PATHS_AND_CASES.md)。
- 就业第一目标：**广泛海投，进入有持续付费客户、成熟上下游业务链条的机器人/工业软件/自动化/机器视觉研发团队，争取连续稳定工作 2–3 年。** 公司盈利不能等价于部门不裁员；只以最新公开证据做尽调。
- 多岗位覆盖：机器人系统软件 C++/Linux/ROS2、运动规划/机械臂软件、工业机器视觉、工业控制软件、嵌入式 Linux/端侧 AI、算法/测试开发（必须有技术开发与自动化能力）；Robot Learning/VLA 中长期保留但不 All-in。
- 分工：专门简历对话负责完整简历文案；主教学对话负责技术教学、岗位JD解读、**按岗位版本检查真实简历证据与技能差距**、面经练习、错题分析及招聘漏斗复盘。按[岗位→简历→面试→考公执行规范](APPLICATION_AND_RESUME_EXECUTION.md)协调，不共享公司商业材料或在公开仓库存放个人完整简历。
- 注意“所有记忆在 GitHub”：只能持久化**明确写入并已提交**的可公开学习进展、选岗原则、题库、错题汇总和下一步动作；对话记录、私有简历、个人测评结果、未提交 WSL 修改不会自动备份或神奇同步。每次必须区分本地、远端。

## 五条训练轨道

1. **机器人能力主线**：Day 课程、ROS2/MoveIt2/TF、C++、控制、视觉、仿真、测试、部署，维持真实代码和测试驱动。
2. **岗位筛选、真实简历多版本与招聘漏斗**：核对085404资格、业务稳定性，按JD以证据库派生机器人/C++、工业视觉、通用软件、国央企信息化四版简历，记录从有效岗位到真人面试。
3. **企业综合测评 + 技术笔试/面试**：数量、逻辑、言语、资料分析、性格/情景，C++/Linux/ROS2、算法机考、项目深挖与STAR；不得将测评等同于已通过简历筛选，性格测评真实自洽。
4. **国考/省考 + 贵州事业单位专项**：行测共有能力，独立的政治理论、常识、**申论**和公务员面试；事业单位**职测+综应**按具体类别练，不与国考混写。
5. **企业与职位尽调**：现金流、客户、交付、团队长期业务、是否真正研发/正规合同；按岗位类型区分地域：体制内/央国企贵州优先、企业研发一线新一线优先。

**不是每家公司都会考全部项目**：每家单位按真实 JD、校招公告、可信一手面经打标签。求职者经验不是官方招聘承诺，2027 届样本不能断言 2028 届政策相同。

> **主动提醒与跨对话续课（2026-10-10已确认）**：先读 [跨对话接力卡](NEXT_CHAT_HANDOFF.md)、[主动导师协议](PROACTIVE_TUTOR_PROTOCOL.md) 与 [间隔复习队列](SPACED_REVIEW_QUEUE.md)，每次开聊/每日任务按到期日主动提醒，不等待用户追问；完成状态仅按用户真实答题/ROS2运行证据更新。GitHub仅保留实际提交的公开学习状态，定时提醒能否弹出取决于任务和通知设置。

## 节奏与自动收集

**秋招总日历（2026-10到2027秋招）**：读 [2027秋招月度里程碑与固定复盘日](AUTUMN_2027_MONTHLY_EXECUTION_PLAN.md)；2027-03-31实习申请准备门槛，2027-06-30正式秋招准备就绪门槛，2027-07起监控真实2028届提前批；每周日19:00和每月1日上午复盘（北京时间）。计划日期不代表已经执行。

- **执行新日协议**：[每日20题与项目/求职推进](DAILY_STUDY_EXECUTION_PROTOCOL.md)。行测**周一至周五**每天60–120分钟、目标约20题（复杂题可15–25），默认4组×5题，题题反馈但不无限纠错；**每天另外至少完成1项项目或求职动作**（建议15–30分钟，有证据才算完成）。原来每天20–35分钟/只答一道题已不再作为总上限。
- 每天检索**新**的公开信息并制作**原创/明确许可的**小题及解法。**来源不足时标记为自编模拟，绝不冒称某厂真题/国考真题**。
- 每日**岗位信息推送**可继续只展示一题/一组的入口，但实际训练要逐组推进约20题，并为项目或求职至少留1项可验证行动；后台原创题目储备与用户完成题数分开统计。来源不足时可自编模拟，注明日期。
- 每周一次错题回顾 + 15–25 分钟限时模拟；**每周至少一次申论专项 20–30 分钟，每两周一题公务员面试情景**。**每次测评或笔面试后及时复盘、每周学习及投递复盘、每月跨方向和城市策略复盘**；公务员招录时间与资格在当年度官方公告出来后重新核对。
- 训练成果与用户反馈经明确确认后填入 [LEARNING_STATE.md](LEARNING_STATE.md)；面经记录放 [SOURCES_AND_METHOD.md](SOURCES_AND_METHOD.md) 并链接原帖。
