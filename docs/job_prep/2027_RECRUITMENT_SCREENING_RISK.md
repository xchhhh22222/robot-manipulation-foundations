## 关键事实：笔试/行测邮件究竟说明什么，**依企业流程**？

- **小米官方2027校招流程**：[小米校招页](https://hr.xiaomi.com/website/campus.html) 明确为 **在线投递→线上测评（专项能力+性格）→HR+业务简历评估→面试→Offer**。因此测评邮件**不等于已通过HR/业务简历评估**。
- **海康威视2027校园招聘**：[高校转载原公告](https://jyw.zjgsu.edu.cn/career/zpxx/view/zpxx/238677344070537216)：测评是简历筛选重要参考，只有完成测评才能进入下一环节；测评每年1次，部分技术类另有笔试。**测评不代表通过业务部门筛选**。
- **华为招聘官方FAQ**：[FAQ](https://career.huawei.com/reccampportal/next/mini/faq_h5.html)：简历通过筛选后，通知考试、综合测评（不同招聘批次问答页面文字不同）；因此公司间**阶段排序不同**，不能凭收到笔试推断完全一样。
- **中核四0四 2027届校招**：[高校就业平台转发](https://whetc.91wllm.cn/campus/view/id/1003661)：明确列出 **网申→简历初筛→测评→笔试→简历复筛→线下面试**，甚至完成笔试仍会经过**简历复筛**。
- 这些公开流程只说明不同企业阶段安排，不证明哪个具体求职者因双非被拒或其行测没达线。

## 为什么“1个月有笔试无面试”无法直接诊断院校歧视

可能原因包括：测评统一发放/先测后筛、笔试分数、JD硬性资格、技术栈/岗位关键词不匹配、实习和项目证据不足、部门HC紧/仅等待批量面试或调整岗位、院校偏好/筛选。缺少原始岗位流程与实际投递时间无法分辨；不能自行断言个人能力不足，也不能乐观声称不存在学校歧视。

## 2028届执行原则：两条战线，明确转化漏斗

### 路线一：解决「得到面试资格」
- 选符合**085404/0854计算机技术+工学学士080910T**的岗位，尤其普通工业机器人系统软件、C++/Linux、嵌入式Linux、工业视觉/机械臂应用、成熟企业自动化软件和技术测试开发；纯VLA核心算法是冲刺，不作唯一渠道。
- 建立**2–3份真实、岗位精准**简历：机器人/C++系统研发；工业视觉/AI工程；运营商/国企信息化（实际研发/非研发区别清楚）。不伪造部署业绩或工业实习产出，不把他人商业代码公开。
- **实习→留用/转正**是一种多样化路径，需询问录用政策、考核及HC，**不保证能转正**。适当关注校企合作宣讲、技术开源贡献、针对部门而非群发拉群内推、候选人紧缺的地区与正规中小规模企业。
- **海投应精准且留数据**：不同平台和城市的技术岗、央国企/银行科技、公考事业编（考试体系独立），限定志愿数岗位优先选最匹配的一项，不要低质量刷量/重复投同岗位。
- 新增可核查官方JD样本：[星猿哲2027具身智能系统工程师](https://career.nankai.edu.cn/correcruit/content/id/117759.html) 招本/硕，C++ Python、3D视觉、坐标变换，ROS2等加分；[思谋科技2026机器人软件岗位](https://www.nowcoder.com/jobs/detail/434391?urlSource=sitemap) 本科及以上（硕士优先）计算机/电子信息，C++/Linux/ROS2和现场联调；公告未写985/211 **≠内部筛选绝不考虑院校**。

### 路线二：解决「笔试/面试能通过」
- 企业通用认知题/行测：数量、资料分析、逻辑、言语。公司流程具体标记“是否先筛简历”，不把其与国考行测混淆。
- 技术笔试：C++/Linux/网络/OS基础 + DSA与限时编程；Day28的MoveIt2、ROS2控制器/Action、真实问题复现与调试日志可作为项目面试经历（须真实、分清仿真与真机）。
- 公考：行测+申论；贵州事业编：职测+综应分类；央国企：按企业公告另备。

### 漏斗台账字段（只写匿名岗位信息，个人申请追踪可存本地私有文件）

`投递日期 / 公司及部门 / 岗位类别 / 城市 / 本硕学历条件 / 企业招聘批次 / 从投递到测评 / 测评是否统一发放 / 测评完成日期 / 笔试类型 / 笔试后状态 / 首次真人技术面日期 / 结果与真实拒信 / 研究自查类别`

**诊断办法**：以“投递时间过去多久 + 同批次别人是否已约面 + 该公司测评和筛选具体先后”判断流程是否推进，不将仍然处理中统一判拒。只有实际数据才计算“简历→测评→真人面试”的转化；**30–50个充分匹配、已过合理处理期的岗位仍0面**可作为需要换岗位组合/检查简历的排查触发器（**教学经验阈值，非就业统计规律或招聘官方标准**）。

## 最优先的2028届动作

- 不等到毕业季才检验CV：**2027春夏实习**就用真实反馈检验学历初筛与项目可迁移性，目标是实际拿到几次工程技术面试和至少一个经本人实现的项目产物。
- 当前ROS2 Day28继续，但尽早开始C++小模块、TF2/视觉误差以及能量化的故障定位/测试证据。
- **用户师兄Agent方向0面**是很重要的风险预警，但Agent应用研发与机器人系统研发市场不是同一个岗位池。不要把一个人一个月的反馈当作“双非进不了所有具身岗位”的证据；也不能假装双非院校不构成劣势。
