# 2026-10-12—12-31 国考行测120分钟整卷能力路线（用户目标）

**用户提出的目标**：2026年12月能够在120分钟内做完一套**国考行测试卷**；不以高分为当前硬要求，先做到见到题不慌、每个模块能启动解题、会及时跳题并做完整卷。**不是行测+申论都限120分钟**。现阶段学习进度真实记录以[LEARNING_STATE](LEARNING_STATE.md)为准，当前尚无整卷模拟成绩/时间证据。

## 现实约束及官方依据

- 2026年度国考官方公共科目大纲：行测为120分钟，申论180分钟；行测**六块**：政治理论、常识判断、言语理解、数量关系、判断推理、资料分析。官网来源：<https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml>（2025-10-16发布的2026年度大纲，**不是2027或2028年度最终公告**）。
- 2026年度真题第三方题量统计：省级135道，市地级/执法类130道；来源<https://www.xbcjy.com/news/05018697.html>，**非官方题量承诺**，不同年份类别以所选试卷当年原题和说明为准。
- 用户已有的四册2025国考版教材以原生**言语、判断、资料、数量、申论**内容为主；政治理论和常识需根据官方大纲及可靠公开来源补充，见[缺口说明](methods/political_common.md)。不能假装四本教材覆盖全部最新国考题型。
- 仍坚持**周一至周五行测60—120分钟，约20题是通常目标而非必须每日固定20道**；周末不派题、不积累欠题。导师学业义务、真实求职行动和未批准启动的嵌入式Linux技术学习不被挤压。

## 六阶段倒排（里程碑为计划，非已经实现）

| 时间窗口 | 学习重点与卷量升级 | 阶段验收方式（未实测就PENDING） |
|---|---|---|
| **10/12—10/23** 基础启动 | 延续每日约20题的小组练习，一次最多补一个当前错点；重点学“如何开始解题”而非背答案；补齐政治理论、常识和图推的入门样题，数量资料优先截位、比重、增长率、工程赋值 | 六大行测模块都至少亲自见过完整选择题；个人能说出各模块一类题的入手步骤；保留错题与计时缺口 |
| **10/26—11/06** 方法覆盖 | 轮换六模块；常态20题+部分分组限时；每周一次30—40题分模块限时测试，逐渐控制“读题－选法－跳题”的节奏 | 30—40题完整作答+记录实际时间、正确数、跳题数；未通过先缩小任务 |
| **11/09—11/20** 半卷训练 | 保持日常60—120分钟，择一工作日尝试60—70题、60—75分钟混合卷；其余工作日按20题左右做针对性订正，含政治常识 | 60—70题混合限时真实记录；统计每模块“看懂题目/会下手/需猜/没时间看”的数量，不能把猜题记掌握 |
| **11/23—12/04** 首次整卷 | 先做90—100题90分钟的节奏练习；最迟12/04（周五）尝试**一套对应类别的120分钟整卷**；整卷当天时间已满则不强制同日长篇复盘 | 记录答题总数、浏览题数、未填数、最后涂卡用时、各科耗时和明显短板；**完成首次测验不等于达标** |
| **12/07—12/18** 修正节奏 | 每周最多1套整卷（若工作与学业许可），复盘安排在其他工作日；优先修“卡一道题过久”“资料估算过慢”“政治常识缺口” | 至少1次完整120分钟实测与前次比较；看是否覆盖全部模块并能及时跳题 |
| **12/21—12/31** 目标验收 | 在工作日完成1—2套对应类别的整卷限时训练，若真实时间/工作负担不允许，优先保留一次有记录的正式模拟 | **目标：120分钟内交一份全题答案（允许并如实标注合理排除/策略性猜测），各模块都经过阅读与取舍，涂卡完成。** 附：有把握答题数、策略猜测数、未读题数、正确率（只作为诊断，不设最低分） |

> “全部有答案”不等于“全部会”：**审过且独立判断**和**时间不够策略猜测**分别计数。首个阶段目标是形成完整的120分钟流程，2027年以后再加大正确率与申论整卷训练。

## 工作日60—120分钟的默认时间盒

- **普通学习日（约90分钟）**：5分钟选到期卡和错点 → 45—65分钟轮换选择题约20题（按难度浮动）→ 15—20分钟错因复盘和**一张**刚需方法卡 → 5分钟登记真实成绩。多余时间留作休息/其他学业，不因题量不足强制补齐。
- **限时混合训练日**：固定若干分钟完成30—70题，余下时间只做少量归因；不可在当天额外叠加“再做20新题”。
- **整卷日**：120分钟全部用在做卷与涂卡；**错题复盘安排其他工作日**，不要求当天学习累计超过2小时。若用户本周已有学业/求职冲突，可顺延整卷而不将欠题滚到周末。
- **申论**：另按可持续时间在工作日建议每周一小题，练材料定位与概括；它是**180分钟的另一科目**，本次12月120分钟指标不包含申论；贵州事业单位职测/综应题型与时间按各自公告安排，不冒充国考统一要求。

## 考卷执行策略的迭代（候选，必须测过才能定）

1. 正式卷头快速确认试卷类别、总题量、各模块位置和涂卡要求。
2. **先做本人更稳的模块**，不会的标记后跳过；单题明显超过时限先作策略标注，不死磕；最终每题选择/涂卡。
3. 真题卷里对数量关系难题允许排除、跳过和策略性猜测，但不能把没看过的全涂题伪称“答得上来”。
4. 训练记录：`paper_id / category / start_end / total / read / reasoned / guessed / unvisited / marked / review_date / score / methods_used`，没有证据填NOT_MEASURED/NOT_ATTEMPTED。
5. 每周五检查是否达到当阶段里程碑（未必达标）；若连续两次任务超时或影响生活与工作，**优先下调卷量/调整模块先后，绝不靠增加工作日的时长补偿**。
