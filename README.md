# Robot Manipulation Foundations

A hands-on robotics project focused on embodied AI, robot manipulation, and ROS2 development.

## Goal

Build a complete robot manipulation pipeline from:

- ROS2
- Robot communication
- Robot kinematics
- Motion planning
- Simulation
- Robot learning
- Vision-Language-Action models
